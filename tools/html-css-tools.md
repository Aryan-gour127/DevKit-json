# HTML, CSS, and JavaScript tools

Avoid entering private source code into public playgrounds. Verify the target browser and framework when testing compatibility.

## CodePen

- **Website:** [codepen.io](https://codepen.io/)
- **Category:** Frontend playground
- **Pricing:** Freemium; verify current plan and visibility settings.
- **Best for:** Sharing small HTML, CSS, and JavaScript demonstrations.
- **Key features:** Live preview and community examples.
- **Advantages:** Quick way to show a minimal reproduction.
- **Limitations:** Public pens can expose submitted code; paid features and limits vary.
- **Official documentation:** [CodePen documentation](https://blog.codepen.io/documentation/)

## JSFiddle

- **Website:** [jsfiddle.net](https://jsfiddle.net/)
- **Category:** Frontend playground
- **Pricing:** Free to access; check current terms.
- **Best for:** Testing and sharing compact web examples.
- **Key features:** Separate HTML, CSS, JavaScript, and result panes.
- **Advantages:** Useful for isolated demonstrations.
- **Limitations:** Not a full project environment; don't post secrets or private code.
- **Official documentation:** [JSFiddle](https://jsfiddle.net/)

## Can I use

- **Website:** [caniuse.com](https://caniuse.com/)
- **Category:** Browser compatibility
- **Pricing:** Free.
- **Best for:** Checking support for web platform features across browsers.
- **Key features:** Compatibility tables and feature search.
- **Advantages:** Helps inform browser support decisions.
- **Limitations:** Support data is not a substitute for testing your actual audience and browsers.
- **Official documentation:** [Can I use](https://caniuse.com/)

## MDN Playground

- **Website:** [developer.mozilla.org/en-US/play](https://developer.mozilla.org/en-US/play)
- **Category:** Web development playground
- **Pricing:** Free.
- **Best for:** Trying browser-focused HTML, CSS, and JavaScript examples.
- **Key features:** Editable examples and live results.
- **Advantages:** Closely connected to MDN learning materials.
- **Limitations:** Not intended to replace a full local development environment.
- **Official documentation:** [MDN Playground](https://developer.mozilla.org/en-US/play)

## StackBlitz

- **Website:** [stackblitz.com](https://stackblitz.com/)
- **Category:** Browser-based development environment
- **Pricing:** Freemium; current project and collaboration limits vary.
- **Best for:** Creating and sharing runnable web project examples.
- **Key features:** Browser-based editor and supported framework templates.
- **Advantages:** Useful for reproductions and learning without local setup.
- **Limitations:** Hosted execution and sharing may require an account; do not expose secrets or private code.
- **Official documentation:** [StackBlitz documentation](https://developer.stackblitz.com/)
