# Regular expression tools

Regex engines differ. Confirm the selected flavor and flags before copying a pattern into another language.

## regex101

- **Website:** [regex101.com](https://regex101.com/)
- **Category:** Regex testing
- **Pricing:** Free to use; check current terms.
- **Best for:** Exploring a regular expression with explanations and matches.
- **Key features:** Multiple engine flavors, match details, and saved examples.
- **Advantages:** Helpful for learning and debugging patterns.
- **Limitations:** Do not enter confidential text; output can differ from another runtime.
- **Official documentation:** [regex101 quick reference](https://regex101.com/)

## RegExr

- **Website:** [regexr.com](https://regexr.com/)
- **Category:** Regex testing and reference
- **Pricing:** Free to access; check current terms.
- **Best for:** Learning regex syntax interactively.
- **Key features:** Live matching, community patterns, and reference.
- **Advantages:** Visual feedback is useful for beginners.
- **Limitations:** Verify the regex flavor against your target environment.
- **Official documentation:** [RegExr](https://regexr.com/)

## MDN regular expressions

- **Website:** [MDN JavaScript regular expressions](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Regular_expressions)
- **Category:** Regex reference
- **Pricing:** Free.
- **Best for:** Writing patterns for JavaScript.
- **Key features:** Syntax guide, examples, and JavaScript-specific behavior.
- **Advantages:** Authoritative browser documentation.
- **Limitations:** JavaScript features may not exist in other regex engines.
- **Official documentation:** [MDN regex guide](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Regular_expressions)

## Regexper

- **Website:** [regexper.com](https://regexper.com/)
- **Category:** Regex visualization
- **Pricing:** Free and open source.
- **Best for:** Visualizing the structure of a regular expression.
- **Key features:** Converts patterns into railroad-style diagrams.
- **Advantages:** Can make complex patterns easier to discuss.
- **Limitations:** Visualization does not prove correctness or performance; avoid confidential patterns.
- **Official documentation:** [Regexper source](https://github.com/javallone/regexper)
