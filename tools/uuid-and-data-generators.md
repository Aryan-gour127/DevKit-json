# UUID and data generators

Use generated data for examples and tests. Do not treat sample data as anonymized real data or place credentials in generator sites.

## UUID standard

- **Website:** [RFC 9562](https://www.rfc-editor.org/rfc/rfc9562.html)
- **Category:** UUID reference
- **Pricing:** Free to read.
- **Best for:** Choosing and understanding UUID formats.
- **Key features:** Current IETF UUID specification.
- **Advantages:** Authoritative reference; many languages include local UUID libraries.
- **Limitations:** UUIDs are identifiers, not secrets or access tokens.
- **Official documentation:** [RFC 9562](https://www.rfc-editor.org/rfc/rfc9562.html)

## Faker

- **Website:** [fakerjs.dev](https://fakerjs.dev/)
- **Category:** Synthetic test data
- **Pricing:** Free and open source.
- **Best for:** Creating realistic-looking data for tests and demos.
- **Key features:** Local library for generating names, addresses, dates, and more.
- **Advantages:** Can generate data locally in a project.
- **Limitations:** Synthetic values may resemble real people; do not use for identity verification.
- **Official documentation:** [Faker documentation](https://fakerjs.dev/guide/)

## JSONPlaceholder

- **Website:** [jsonplaceholder.typicode.com](https://jsonplaceholder.typicode.com/)
- **Category:** Dummy REST API
- **Pricing:** Free public test service; check its current usage terms.
- **Best for:** Learning HTTP clients against a simple sample API.
- **Key features:** Example posts, users, comments, and related endpoints.
- **Advantages:** Convenient for tutorials and demos.
- **Limitations:** Public test data is not a production backend; behavior and persistence are intentionally limited.
- **Official documentation:** [JSONPlaceholder guide](https://jsonplaceholder.typicode.com/guide/)

## Lorem Ipsum

- **Website:** [loremipsum.io](https://loremipsum.io/)
- **Category:** Placeholder text
- **Pricing:** Free to access; verify current site terms.
- **Best for:** Temporary layout copy in mockups.
- **Key features:** Generate sample placeholder text.
- **Advantages:** Keeps design drafts moving before copy is ready.
- **Limitations:** Replace placeholder text before publishing user-facing content.
- **Official documentation:** [Lorem Ipsum](https://loremipsum.io/)

## UUID Generator

- **Website:** [uuidgenerator.net](https://www.uuidgenerator.net/)
- **Category:** UUID generation
- **Pricing:** Free to access; verify current site terms.
- **Best for:** Creating sample UUID values for demos and test fixtures.
- **Key features:** Browser-based UUID generation.
- **Advantages:** Quick way to create non-sensitive sample identifiers.
- **Limitations:** Do not use generated identifiers as authentication secrets; use a trusted local generator where needed.
- **Official documentation:** [RFC 9562 UUID specification](https://www.rfc-editor.org/rfc/rfc9562.html)
