# JSON tools

Online JSON tools are convenient for non-sensitive samples. Do not paste production data, credentials, or private records into a third-party page.

## JSON Formatter & Validator — JSONLint

- **Website:** [jsonlint.com](https://jsonlint.com/)
- **Category:** JSON
- **Pricing:** Free to use; check the site's current terms.
- **Best for:** Checking syntax and formatting small JSON documents.
- **Key features:** Validation and readable formatting.
- **Advantages:** Simple browser workflow; no setup.
- **Limitations:** Avoid sensitive input; not a schema validator.
- **Official documentation:** [JSONLint](https://jsonlint.com/)

## JSON Formatter — Prettier Playground

- **Website:** [prettier.io/playground](https://prettier.io/playground/)
- **Category:** JSON and code formatting
- **Pricing:** Free, open-source formatter.
- **Best for:** Formatting JSON and comparing formatter options.
- **Key features:** Prettier formatting and options preview.
- **Advantages:** Uses the Prettier project; supports multiple languages.
- **Limitations:** Browser playground is not a substitute for local project configuration.
- **Official documentation:** [Prettier documentation](https://prettier.io/docs/)

## JSON Viewer — JSON Crack

- **Website:** [jsoncrack.com](https://jsoncrack.com/)
- **Category:** JSON visualization
- **Pricing:** Freemium; features and limits may change.
- **Best for:** Exploring nested JSON as a graph.
- **Key features:** Visual JSON representation and editing.
- **Advantages:** Makes large nested structures easier to inspect.
- **Limitations:** Online input is sent to a third-party service; review its privacy policy and current plan.
- **Official documentation:** [JSON Crack](https://jsoncrack.com/)

## JSON-to-TypeScript — quicktype

- **Website:** [quicktype.io](https://quicktype.io/)
- **Category:** Data model generation
- **Pricing:** Free and open source.
- **Best for:** Generating typed model definitions from representative JSON.
- **Key features:** Generates types for several programming languages.
- **Advantages:** Helps bootstrap models from sample payloads.
- **Limitations:** Generated types require review; sample data should not be confidential.
- **Official documentation:** [quicktype GitHub project](https://github.com/glideapps/quicktype)

## JSON Schema

- **Website:** [json-schema.org](https://json-schema.org/)
- **Category:** JSON validation and schema reference
- **Pricing:** Free and open source specification.
- **Best for:** Describing and validating the expected shape of JSON data.
- **Key features:** Schema documentation and links to validators for different languages.
- **Advantages:** A portable way to document data constraints.
- **Limitations:** A schema only validates rules that have been expressed; implementation support can vary by draft.
- **Official documentation:** [JSON Schema documentation](https://json-schema.org/learn/getting-started-step-by-step)
