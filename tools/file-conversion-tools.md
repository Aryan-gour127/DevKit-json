# File conversion tools

Before uploading a file, consider whether it contains personal, confidential, or proprietary information. Keep an original copy and verify converted output.

## Pandoc

- **Website:** [pandoc.org](https://pandoc.org/)
- **Category:** Document conversion
- **Pricing:** Free and open source.
- **Best for:** Converting between document and markup formats locally.
- **Key features:** Command-line conversion across many formats.
- **Advantages:** Repeatable workflows and no third-party upload required.
- **Limitations:** Some formats require additional tools; conversion may not preserve every layout detail.
- **Official documentation:** [Pandoc documentation](https://pandoc.org/MANUAL.html)

## LibreOffice

- **Website:** [libreoffice.org](https://www.libreoffice.org/)
- **Category:** Office documents
- **Pricing:** Free and open source.
- **Best for:** Opening, editing, and exporting common office documents locally.
- **Key features:** Word processing, spreadsheets, presentations, and PDF export.
- **Advantages:** Desktop workflow works without uploading files.
- **Limitations:** Complex proprietary document layouts may render differently.
- **Official documentation:** [LibreOffice help](https://help.libreoffice.org/)

## CloudConvert

- **Website:** [cloudconvert.com](https://cloudconvert.com/)
- **Category:** Online file conversion
- **Pricing:** Freemium; current quotas and plans vary.
- **Best for:** Converting supported files through a browser or API.
- **Key features:** Broad format support and conversion options.
- **Advantages:** Convenient when local software is unavailable.
- **Limitations:** Files are processed by a third party; review privacy, retention, and pricing before use.
- **Official documentation:** [CloudConvert API documentation](https://cloudconvert.com/api/v2)

## FFmpeg

- **Website:** [ffmpeg.org](https://ffmpeg.org/)
- **Category:** Audio and video conversion
- **Pricing:** Free and open source.
- **Best for:** Local media conversion, inspection, and processing.
- **Key features:** Command-line tools for many audio/video formats.
- **Advantages:** Flexible and scriptable without uploading media.
- **Limitations:** Command-line learning curve; codec and distribution licensing can differ.
- **Official documentation:** [FFmpeg documentation](https://ffmpeg.org/documentation.html)

## HandBrake

- **Website:** [handbrake.fr](https://handbrake.fr/)
- **Category:** Video conversion
- **Pricing:** Free and open source.
- **Best for:** Converting video files with a desktop interface.
- **Key features:** Presets and configurable encoding.
- **Advantages:** Local processing and approachable controls.
- **Limitations:** Conversion can reduce quality; not every media format or DRM-protected file is supported.
- **Official documentation:** [HandBrake documentation](https://handbrake.fr/docs/)
