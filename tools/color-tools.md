# Color tools

Check color contrast for readable text and controls. A palette preview is not a substitute for accessibility testing in context.

## WebAIM Contrast Checker

- **Website:** [webaim.org/resources/contrastchecker](https://webaim.org/resources/contrastchecker/)
- **Category:** Accessibility and contrast
- **Pricing:** Free.
- **Best for:** Testing foreground/background contrast ratios.
- **Key features:** Contrast ratio and WCAG threshold results.
- **Advantages:** Clear accessibility-focused output.
- **Limitations:** Checks a color pair only; does not assess the whole interface.
- **Official documentation:** [WebAIM contrast resources](https://webaim.org/resources/contrastchecker/)

## Adobe Color

- **Website:** [color.adobe.com](https://color.adobe.com/)
- **Category:** Palette creation
- **Pricing:** Free access for core web features; account and product terms may vary.
- **Best for:** Exploring color harmonies and extracting palettes.
- **Key features:** Color wheel and palette tools.
- **Advantages:** Helpful visual starting point for a design system.
- **Limitations:** Palette harmony alone does not ensure text accessibility.
- **Official documentation:** [Adobe Color](https://color.adobe.com/)

## Color.review

- **Website:** [color.review](https://color.review/)
- **Category:** Color accessibility
- **Pricing:** Free to access; confirm current terms.
- **Best for:** Previewing color combinations and contrast.
- **Key features:** Contrast and color pairing guidance.
- **Advantages:** Encourages accessible choices during design.
- **Limitations:** Verify contrast with the applicable WCAG criteria and final rendered styles.
- **Official documentation:** [Color.review](https://color.review/)

## MDN CSS color

- **Website:** [MDN CSS colors](https://developer.mozilla.org/en-US/docs/Web/CSS/color_value)
- **Category:** CSS color reference
- **Pricing:** Free.
- **Best for:** Learning CSS color syntax and supported color formats.
- **Key features:** Syntax explanations and examples.
- **Advantages:** Authoritative browser documentation.
- **Limitations:** A syntax reference does not choose an accessible palette for you.
- **Official documentation:** [MDN color values](https://developer.mozilla.org/en-US/docs/Web/CSS/color_value)

## Coolors

- **Website:** [coolors.co](https://coolors.co/)
- **Category:** Palette generation
- **Pricing:** Freemium; check current plan limits.
- **Best for:** Exploring and saving color palettes.
- **Key features:** Palette generation and color exploration.
- **Advantages:** Fast visual ideation.
- **Limitations:** Generated palettes still need contrast and accessibility checks.
- **Official documentation:** [Coolors](https://coolors.co/)
