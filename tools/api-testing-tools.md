# API testing tools

Use test or synthetic data when sending requests. Never store real credentials in shared collections or public examples.

## Postman

- **Website:** [postman.com](https://www.postman.com/)
- **Category:** API development and testing
- **Pricing:** Freemium; current plan limits and collaboration features vary.
- **Best for:** Building, sending, and organizing HTTP API requests.
- **Key features:** Collections, environments, scripted tests, and collaboration.
- **Advantages:** Broad ecosystem and learning material.
- **Limitations:** Account and paid plan may be needed for some collaboration features.
- **Official documentation:** [Postman Learning Center](https://learning.postman.com/)

## Insomnia

- **Website:** [insomnia.rest](https://insomnia.rest/)
- **Category:** API client
- **Pricing:** Freemium; verify current plan details.
- **Best for:** Organizing and testing REST and GraphQL requests.
- **Key features:** Request collections, environments, and API workflows.
- **Advantages:** Desktop client with a focused request interface.
- **Limitations:** Advanced team and hosted features may have plan requirements.
- **Official documentation:** [Insomnia documentation](https://docs.insomnia.rest/)

## Hoppscotch

- **Website:** [hoppscotch.io](https://hoppscotch.io/)
- **Category:** API client
- **Pricing:** Free and open source; hosted service terms may differ.
- **Best for:** Quickly trying HTTP requests in a browser.
- **Key features:** REST, GraphQL, WebSocket, and other request types.
- **Advantages:** Browser-based and also self-hostable.
- **Limitations:** Browser security restrictions can affect cross-origin requests; never put secrets in shared workspaces.
- **Official documentation:** [Hoppscotch documentation](https://docs.hoppscotch.io/)

## Bruno

- **Website:** [usebruno.com](https://www.usebruno.com/)
- **Category:** API client
- **Pricing:** Free, open source; check current details for optional products.
- **Best for:** Keeping API collections as files alongside a project.
- **Key features:** Local collections and environment variables.
- **Advantages:** File-based workflow can be reviewed with version control.
- **Limitations:** Desktop installation is required; protect secret environment values.
- **Official documentation:** [Bruno documentation](https://docs.usebruno.com/)

## Swagger Editor

- **Website:** [editor.swagger.io](https://editor.swagger.io/)
- **Category:** API description and design
- **Pricing:** Free and open source.
- **Best for:** Writing and previewing OpenAPI descriptions.
- **Key features:** API definition editing and rendered documentation preview.
- **Advantages:** Helps spot specification issues while designing an API.
- **Limitations:** It is an API description editor, not a complete API load or security testing suite.
- **Official documentation:** [Swagger Editor repository](https://github.com/swagger-api/swagger-editor)
