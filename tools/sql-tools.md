# SQL tools

Use disposable sample data for online SQL editors. Never upload production data or credentials to an untrusted service.

## DB Fiddle

- **Website:** [db-fiddle.com](https://www.db-fiddle.com/)
- **Category:** SQL playground
- **Pricing:** Free to access; verify current service terms.
- **Best for:** Sharing small SQL examples for supported database engines.
- **Key features:** Browser editor and schema/query execution.
- **Advantages:** Useful for reproducible questions and demos.
- **Limitations:** Engine versions and availability may change; never use sensitive data.
- **Official documentation:** [DB Fiddle](https://www.db-fiddle.com/)

## SQL Fiddle

- **Website:** [sqlfiddle.com](https://sqlfiddle.com/)
- **Category:** SQL playground
- **Pricing:** Free to access; confirm current limits.
- **Best for:** Trying compact SQL examples in a browser.
- **Key features:** Schema setup and query testing for available engines.
- **Advantages:** No local database installation for small examples.
- **Limitations:** Availability, engine versions, and limits may vary.
- **Official documentation:** [SQL Fiddle](https://sqlfiddle.com/)

## SQLite

- **Website:** [sqlite.org](https://sqlite.org/)
- **Category:** Local database
- **Pricing:** Public domain software.
- **Best for:** Learning SQL or using a lightweight embedded database locally.
- **Key features:** Self-contained database engine and official docs.
- **Advantages:** Local use avoids sending sample data to a web service.
- **Limitations:** Not a drop-in replacement for a client/server database in every workload.
- **Official documentation:** [SQLite documentation](https://sqlite.org/docs.html)

## PostgreSQL Exercises

- **Website:** [pgexercises.com](https://pgexercises.com/)
- **Category:** SQL learning
- **Pricing:** Free.
- **Best for:** Practicing PostgreSQL query concepts with guided exercises.
- **Key features:** Interactive exercises from basic to advanced.
- **Advantages:** Exercises are paired with explanations.
- **Limitations:** Focuses on PostgreSQL syntax and behavior.
- **Official documentation:** [PostgreSQL documentation](https://www.postgresql.org/docs/)

## SQLZoo

- **Website:** [sqlzoo.net](https://sqlzoo.net/)
- **Category:** SQL learning and practice
- **Pricing:** Free to access; check current site terms.
- **Best for:** Practicing SQL through short interactive lessons.
- **Key features:** Query exercises and topic-based tutorials.
- **Advantages:** Friendly entry point for learning query syntax.
- **Limitations:** Exercise environment is for learning, not production data or performance testing.
- **Official documentation:** [SQLZoo](https://sqlzoo.net/)
