# Productivity tools

Choose tools that fit your team's privacy, accessibility, and retention requirements. Free plans often have limits.

## Obsidian

- **Website:** [obsidian.md](https://obsidian.md/)
- **Category:** Notes and knowledge management
- **Pricing:** Free for personal use; commercial use and optional services have separate terms.
- **Best for:** Linking personal notes stored as local Markdown files.
- **Key features:** Local files, backlinks, and a plugin ecosystem.
- **Advantages:** Markdown notes remain readable outside the application.
- **Limitations:** Sync and publishing services may cost extra; plugins are third-party code.
- **Official documentation:** [Obsidian Help](https://help.obsidian.md/)

## Todoist

- **Website:** [todoist.com](https://todoist.com/)
- **Category:** Task management
- **Pricing:** Freemium; plan limits change.
- **Best for:** Organizing personal and shared tasks.
- **Key features:** Projects, due dates, and cross-device task lists.
- **Advantages:** Available across common platforms.
- **Limitations:** Advanced features and collaboration may require a paid plan.
- **Official documentation:** [Todoist Help Center](https://todoist.com/help)

## Focus To-Do

- **Website:** [focus-to-do.com](https://www.focustodo.cn/)
- **Category:** Focus timer and task planning
- **Pricing:** Freemium; verify current platform terms.
- **Best for:** Combining timed focus sessions with a task list.
- **Key features:** Pomodoro-style timer and task tracking.
- **Advantages:** Lightweight structure for focused work.
- **Limitations:** Availability and premium features can vary by platform.
- **Official documentation:** [Focus To-Do](https://www.focustodo.cn/)

## GitHub Projects

- **Website:** [github.com/features/issues](https://github.com/features/issues)
- **Category:** Project planning
- **Pricing:** Free features available; organization plan limits and terms apply.
- **Best for:** Tracking work connected to GitHub repositories.
- **Key features:** Issues, project boards, and workflow integration.
- **Advantages:** Keeps planning close to code and discussions.
- **Limitations:** Requires a GitHub account; feature availability depends on plan and permissions.
- **Official documentation:** [GitHub Projects docs](https://docs.github.com/en/issues/planning-and-tracking-with-projects)

## Clockify

- **Website:** [clockify.me](https://clockify.me/)
- **Category:** Time tracking
- **Pricing:** Freemium; current plan features and limits may change.
- **Best for:** Recording time spent on tasks and projects.
- **Key features:** Timers and timesheets across supported platforms.
- **Advantages:** Can help teams understand work allocation.
- **Limitations:** Requires an account for many workflows; review privacy and organizational policies.
- **Official documentation:** [Clockify Help](https://clockify.me/help)
