# Markdown tools

Markdown rendering varies by platform. Preview in the destination service, especially for tables, alerts, and embedded HTML.

## CommonMark specification

- **Website:** [commonmark.org](https://commonmark.org/)
- **Category:** Markdown reference
- **Pricing:** Free.
- **Best for:** Checking portable Markdown syntax.
- **Key features:** Specification and reference implementations.
- **Advantages:** Defines a consistent baseline.
- **Limitations:** GitHub and other platforms add extensions beyond CommonMark.
- **Official documentation:** [CommonMark specification](https://spec.commonmark.org/)

## GitHub Flavored Markdown

- **Website:** [github.github.com/gfm](https://github.github.com/gfm/)
- **Category:** Markdown reference
- **Pricing:** Free.
- **Best for:** Writing Markdown intended for GitHub.
- **Key features:** GFM specification, including tables and task lists.
- **Advantages:** Matches GitHub's published syntax rules.
- **Limitations:** Not every Markdown host supports all GFM features.
- **Official documentation:** [GitHub Markdown guide](https://docs.github.com/en/get-started/writing-on-github)

## Dillinger

- **Website:** [dillinger.io](https://dillinger.io/)
- **Category:** Markdown editor
- **Pricing:** Free to access; check current terms.
- **Best for:** Drafting Markdown with a live preview.
- **Key features:** Editor, preview, and export integrations.
- **Advantages:** No local setup needed.
- **Limitations:** Review privacy and account requirements before using private documents.
- **Official documentation:** [Dillinger](https://dillinger.io/)

## Markdownlint

- **Website:** [github.com/DavidAnson/markdownlint](https://github.com/DavidAnson/markdownlint)
- **Category:** Markdown quality
- **Pricing:** Free and open source.
- **Best for:** Finding style and consistency issues in Markdown files.
- **Key features:** Rules, editor integrations, and command-line linting.
- **Advantages:** Can run locally and in continuous integration.
- **Limitations:** Rules are configurable; a clean lint does not guarantee clear writing.
- **Official documentation:** [markdownlint README](https://github.com/DavidAnson/markdownlint)

## Visual Studio Code Markdown preview

- **Website:** [code.visualstudio.com/docs/languages/markdown](https://code.visualstudio.com/docs/languages/markdown)
- **Category:** Markdown authoring
- **Pricing:** Free editor feature.
- **Best for:** Editing Markdown with a local preview.
- **Key features:** Preview, outline navigation, and Markdown editing support.
- **Advantages:** Works with local files and keeps drafts on your machine.
- **Limitations:** The preview may not exactly match every hosting platform.
- **Official documentation:** [VS Code Markdown docs](https://code.visualstudio.com/docs/languages/markdown)
