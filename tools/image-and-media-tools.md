# Image and media tools

Consider image licensing, metadata, and privacy before uploading files. Keep originals when optimizing assets.

## Squoosh

- **Website:** [squoosh.app](https://squoosh.app/)
- **Category:** Image optimization
- **Pricing:** Free and open source.
- **Best for:** Comparing image formats and compression settings.
- **Key features:** Side-by-side previews and export settings.
- **Advantages:** Useful visual quality/size comparison.
- **Limitations:** Confirm browser-side processing and privacy behavior for sensitive images; output quality needs review.
- **Official documentation:** [Squoosh repository](https://github.com/GoogleChromeLabs/squoosh)

## ImageMagick

- **Website:** [imagemagick.org](https://imagemagick.org/)
- **Category:** Local image processing
- **Pricing:** Free and open source.
- **Best for:** Batch image conversion and transformation on a local machine.
- **Key features:** Command-line image operations and broad format support.
- **Advantages:** Reproducible local workflows.
- **Limitations:** Installation and command-line familiarity are required; review license and delegates for your use case.
- **Official documentation:** [ImageMagick documentation](https://imagemagick.org/script/command-line-tools.php)

## TinyPNG

- **Website:** [tinypng.com](https://tinypng.com/)
- **Category:** Image compression
- **Pricing:** Freemium; upload limits and paid plans may change.
- **Best for:** Compressing common web image formats.
- **Key features:** Browser-based image optimization.
- **Advantages:** Simple workflow for non-sensitive assets.
- **Limitations:** Files are uploaded to a third party; check current privacy and usage terms.
- **Official documentation:** [TinyPNG developer API](https://tinypng.com/developers)

## ExifTool

- **Website:** [exiftool.org](https://exiftool.org/)
- **Category:** Media metadata
- **Pricing:** Free and open source.
- **Best for:** Inspecting and managing image, audio, and video metadata locally.
- **Key features:** Reads and writes many metadata formats.
- **Advantages:** Powerful local option for privacy-aware workflows.
- **Limitations:** Command-line tool; metadata edits can be irreversible without backups.
- **Official documentation:** [ExifTool documentation](https://exiftool.org/)

## ImageOptim

- **Website:** [imageoptim.com](https://imageoptim.com/)
- **Category:** Image optimization
- **Pricing:** Free macOS application; check current distribution terms.
- **Best for:** Optimizing images locally before publishing.
- **Key features:** GUI workflow for image compression.
- **Advantages:** Local processing avoids uploading images to a web converter.
- **Limitations:** Platform availability is limited; retain originals and check output quality.
- **Official documentation:** [ImageOptim](https://imageoptim.com/)
