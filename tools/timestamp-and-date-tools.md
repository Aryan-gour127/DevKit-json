# Timestamp and date tools

Time zones, daylight-saving rules, and timestamp precision matter. Check units and zone explicitly before using a converted value.

## Epoch Converter

- **Website:** [epochconverter.com](https://www.epochconverter.com/)
- **Category:** Timestamp conversion
- **Pricing:** Free to access; check current terms.
- **Best for:** Converting Unix timestamps and human-readable dates.
- **Key features:** Timestamp conversion and date/time displays.
- **Advantages:** Quick reference for common epoch formats.
- **Limitations:** Confirm seconds versus milliseconds and the intended time zone.
- **Official documentation:** [Unix time overview](https://en.wikipedia.org/wiki/Unix_time)

## IANA Time Zone Database

- **Website:** [iana.org/time-zones](https://www.iana.org/time-zones)
- **Category:** Time zone reference
- **Pricing:** Free.
- **Best for:** Understanding authoritative time-zone rules and database updates.
- **Key features:** IANA database releases and background.
- **Advantages:** Primary source used by many operating systems and runtimes.
- **Limitations:** Local runtime database versions may lag behind current updates.
- **Official documentation:** [IANA Time Zone Database](https://www.iana.org/time-zones)

## JavaScript Date reference

- **Website:** [MDN Date](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Date)
- **Category:** Date programming reference
- **Pricing:** Free.
- **Best for:** Understanding JavaScript date values and APIs.
- **Key features:** Constructor, parsing, conversion, and compatibility information.
- **Advantages:** Practical reference with examples.
- **Limitations:** Parsing arbitrary date strings can be inconsistent; use an explicit format.
- **Official documentation:** [MDN Date](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Date)

## Temporal proposal

- **Website:** [tc39.es/proposal-temporal](https://tc39.es/proposal-temporal/)
- **Category:** Date/time programming
- **Pricing:** Free specification.
- **Best for:** Learning modern date/time API design.
- **Key features:** Types for instants, dates, times, and time zones.
- **Advantages:** Makes time-zone and calendar concepts more explicit.
- **Limitations:** Runtime support varies; check compatibility before adoption.
- **Official documentation:** [Temporal proposal](https://tc39.es/proposal-temporal/)

## timeanddate.com

- **Website:** [timeanddate.com/date](https://www.timeanddate.com/date/)
- **Category:** Date and calendar calculations
- **Pricing:** Free tools available; check current site terms.
- **Best for:** Looking up calendar dates and common date calculations.
- **Key features:** Calendar, date, and time-zone references.
- **Advantages:** Useful general reference for everyday conversions.
- **Limitations:** Verify time zone, locale, and daylight-saving assumptions for technical use.
- **Official documentation:** [Time and Date](https://www.timeanddate.com/)
