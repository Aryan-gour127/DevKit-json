# Security policy

DevKit is a documentation-only repository. It does not distribute application code, but linked third-party websites and recommendations can change.

## Reporting a security concern

Do not post credentials, private tokens, personal data, or details of an unpatched vulnerability in a public issue. Contact the maintainers privately at **[security contact to be added]** with the affected page or link and a concise description. Do not send secrets or exploit payloads.

If no private contact has been configured, report only the non-sensitive location of the concern through the repository's private vulnerability-reporting feature, if enabled. Otherwise ask a maintainer for a private channel without disclosing technical details publicly.

## Safe use of linked tools

Never paste confidential data, production credentials, API keys, private JWTs, or personal information into an online utility unless you have reviewed and trust its data handling. Prefer local or first-party tools for sensitive material. Verify links and provider terms before use.
