# Keyboard shortcuts

Shortcuts depend on operating system, application, keyboard layout, and user settings. Replace `Ctrl` with `Command` on macOS in many applications.

| Action | Common shortcut |
| --- | --- |
| Copy / paste / cut | `Ctrl+C` / `Ctrl+V` / `Ctrl+X` |
| Undo / redo | `Ctrl+Z` / `Ctrl+Y` (redo differs by app) |
| Find | `Ctrl+F` |
| Save | `Ctrl+S` |
| Select all | `Ctrl+A` |
| Switch applications | `Alt+Tab` (Windows/Linux) |
| Browser new tab | `Ctrl+T` |
| Browser reopen closed tab | `Ctrl+Shift+T` |
| VS Code Command Palette | `Ctrl+Shift+P` |
| VS Code quick open | `Ctrl+P` |

Check the application's own keyboard-shortcut reference when a shortcut differs. Official VS Code reference: [Keyboard shortcuts for Windows](https://code.visualstudio.com/shortcuts/keyboard-shortcuts-windows.pdf).
