# Markdown cheat sheet

````md
# Heading 1
## Heading 2

**bold** and *italic* and ~~strikethrough~~

[Link text](https://example.com)
![Image description](image.png)

- Unordered item
1. Ordered item
- [ ] Task
- [x] Completed task

> Block quote

`inline code`

```text
code block
```

| Column | Value |
| --- | --- |
| Example | Text |
````

Use descriptive link text and meaningful alt text. Fence code blocks with a language identifier when known. Tables, task lists, and embedded HTML are extensions and may not render on every platform.

References: [CommonMark](https://commonmark.org/help/), [GitHub Markdown guide](https://docs.github.com/en/get-started/writing-on-github).
