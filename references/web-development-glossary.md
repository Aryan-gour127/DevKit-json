# Web development glossary

| Term | Meaning |
| --- | --- |
| API | Interface through which software systems exchange requests and responses |
| Accessibility (a11y) | Designing technology so people with differing abilities can use it |
| Backend | Server-side systems such as application logic, storage, and APIs |
| Browser DOM | Structured object representation of a document used by browser code |
| Cache | Stored result used to avoid repeating work or fetching unchanged data |
| CI/CD | Automated practices for integrating, testing, and delivering software |
| Client | Software or device that requests a service |
| CORS | Browser-enforced rules governing cross-origin resource access |
| DNS | System that maps domain names to network records |
| Framework | Reusable structure and conventions for building software |
| Frontend | User-facing interface and browser-side behavior |
| HTTP | Protocol commonly used to exchange web requests and responses |
| JSON | Text format for structured data |
| Middleware | Component that processes a request or response within a pipeline |
| REST | Architectural style often used to design HTTP APIs |
| Responsive design | Layout behavior adapted to different screen sizes and contexts |
| Semantic HTML | HTML elements chosen to convey document meaning |
| TLS / HTTPS | Encryption and authentication used to protect network connections |
| TypeScript | JavaScript with a static type system |
| UI / UX | User interface / user experience |

See [MDN Web Glossary](https://developer.mozilla.org/en-US/docs/Glossary) for a broader reference.
