# Free programming courses

These resources offer free learning material at the time of writing. Certificates, mentoring, hosted environments, or some course features may be paid or limited; check each provider's current terms.

| Area | Resource | Audience and focus |
| --- | --- | --- |
| Web development | [freeCodeCamp](https://www.freecodecamp.org/learn/) | Beginner-friendly interactive curriculum and projects |
| Web development | [The Odin Project](https://www.theodinproject.com/) | Self-directed, project-based web curriculum |
| Python | [Python for Everybody](https://www.py4e.com/) | Introductory Python lessons and exercises |
| Data structures and algorithms | [Open Data Structures](https://opendatastructures.org/) | Free text on fundamental data structures |
| Databases | [SQLBolt](https://sqlbolt.com/) | Interactive SQL basics |
| Linux | [Linux Journey](https://linuxjourney.com/) | Introductory Linux lessons |
| AI and machine learning | [Google ML Crash Course](https://developers.google.com/machine-learning/crash-course) | Practical machine-learning concepts and exercises |
| Cloud computing | [AWS Skill Builder](https://skillbuilder.aws/) | Official cloud learning; free and paid offerings vary |
| DevOps | [Microsoft Learn](https://learn.microsoft.com/training/) | Self-paced technical learning paths; offerings vary |
