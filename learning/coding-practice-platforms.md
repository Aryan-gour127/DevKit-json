# Coding practice platforms

Free access and premium features may change. Do not submit confidential code or personal data to public profiles.

| Platform | Practice focus | Pricing note |
| --- | --- | --- |
| [Exercism](https://exercism.org/) | Language exercises and community mentoring | Free learning platform; verify current program details |
| [Codewars](https://www.codewars.com/) | Short programming challenges | Free access with platform-specific features |
| [LeetCode](https://leetcode.com/) | Algorithms and interview-style problems | Freemium; some content and features require subscription |
| [HackerRank](https://www.hackerrank.com/) | Programming, SQL, and skill assessments | Free practice; employer and premium offerings vary |
| [SQLBolt](https://sqlbolt.com/) | Interactive SQL lessons | Free |
| [Kaggle Learn](https://www.kaggle.com/learn) | Short data science and ML lessons | Free learning content; platform features and terms apply |
| [Project Euler](https://projecteuler.net/) | Mathematical programming puzzles | Free |

Use practice sites to learn patterns, then build projects that require testing, documentation, and maintenance.
