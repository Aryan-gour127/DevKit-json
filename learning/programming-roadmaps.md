# Programming roadmaps

Roadmaps are orientation tools, not mandatory checklists. Pick a path that matches a goal and build small projects as you learn.

| Goal | Suggested sequence | Reference |
| --- | --- | --- |
| Web frontend | HTML and accessibility → CSS → JavaScript → browser APIs → framework → testing | [MDN Learn](https://developer.mozilla.org/en-US/docs/Learn) |
| Python | Core syntax → functions and modules → files and exceptions → tests → a small automation or web project | [Python tutorial](https://docs.python.org/3/tutorial/) |
| Backend/API | Language basics → HTTP → one server framework → validation/auth basics → database → tests and deployment | [roadmap.sh backend](https://roadmap.sh/backend) |
| Data structures and algorithms | Arrays/strings → maps/sets → stacks/queues → trees/graphs → complexity → timed practice | [VisuAlgo](https://visualgo.net/en) |
| Databases | Relational concepts → SQL → joins/indexes → transactions → one database → backups and migrations | [PostgreSQL tutorial](https://www.postgresql.org/docs/current/tutorial.html) |
| AI/ML | Python → data handling → statistics → classical ML → evaluation → deep learning basics | [Google ML Crash Course](https://developers.google.com/machine-learning/crash-course) |
| DevOps | Linux and networking → Git → containers → CI → deployment → monitoring and security | [roadmap.sh DevOps](https://roadmap.sh/devops) |

The linked roadmaps are free to read; some provider platforms also sell services or courses. Confirm current terms.
