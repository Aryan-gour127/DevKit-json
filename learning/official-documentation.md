# Official documentation

First-party docs describe supported behavior and should be checked when tutorials conflict or become outdated.

| Technology | Documentation | Useful for |
| --- | --- | --- |
| HTML, CSS, JavaScript | [MDN](https://developer.mozilla.org/en-US/docs/Learn) | Web platform tutorials and reference |
| TypeScript | [TypeScript Handbook](https://www.typescriptlang.org/docs/handbook/intro.html) | Language features and types |
| Python | [Python docs](https://docs.python.org/3/) | Language, standard library, and tutorials |
| Node.js | [Node.js docs](https://nodejs.org/docs/latest/api/) | Runtime APIs |
| React | [React docs](https://react.dev/learn) | React concepts and practical guides |
| Vue | [Vue docs](https://vuejs.org/guide/) | Vue application development |
| Django | [Django docs](https://docs.djangoproject.com/) | Python web framework |
| PostgreSQL | [PostgreSQL docs](https://www.postgresql.org/docs/) | Relational database |
| Docker | [Docker docs](https://docs.docker.com/) | Containers and tooling |
| Git | [Git docs](https://git-scm.com/doc) | Version control reference |
| GitHub | [GitHub Docs](https://docs.github.com/en) | Repository hosting and collaboration |
| GraphQL | [GraphQL docs](https://graphql.org/learn/) | Query language and API concepts |
| Kubernetes | [Kubernetes docs](https://kubernetes.io/docs/home/) | Container orchestration |

Documentation is free to read; hosting, support, and related services may be paid.
