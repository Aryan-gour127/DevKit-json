# Project ideas

These are learning prompts, not complete implementations. Keep the scope small, write down requirements, and use synthetic data.

## Beginner

| Idea | Learning objectives |
| --- | --- |
| Personal profile page | Semantic HTML, responsive CSS, accessible links, and deployment |
| Command-line unit converter | Input validation, functions, and automated tests |
| Markdown notes index | File formats, search, and clear documentation |
| Public API explorer | HTTP requests, loading/error states, and responsible API usage |

## Intermediate

| Idea | Learning objectives |
| --- | --- |
| Reading list with persistence | CRUD concepts, database schema, validation, and migrations |
| Habit tracker | Date/time handling, accessible forms, and test design |
| API status dashboard | Polling, rate limits, caching, and clear failure states |
| Collaborative issue board | Authentication concepts, authorization, and audit-friendly changes |

## Advanced

| Idea | Learning objectives |
| --- | --- |
| Searchable documentation portal | Indexing, accessible search, and performance measurement |
| Event-driven notification demo | Queues, retries, idempotency, and observability |
| Reproducible ML experiment | Dataset provenance, evaluation, baselines, and model limitations |
| Multi-service deployment exercise | Containers, CI, secrets management, monitoring, and rollback |

Never expose credentials, scrape services against their terms, or use personal data without an appropriate basis and safeguards.
