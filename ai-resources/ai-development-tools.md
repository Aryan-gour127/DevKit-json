# AI development tools

Hosted services may process prompts or code and impose usage limits. Check current pricing, data retention, training, and privacy terms before sharing sensitive material.

## GitHub Copilot

- **Website:** [github.com/features/copilot](https://github.com/features/copilot)
- **Category:** AI coding assistant
- **Pricing:** Paid plans and eligibility-based free access may be available; confirm current terms.
- **Best for:** Code suggestions and development assistance inside supported editors.
- **Key features:** Code completion and chat features, depending on plan and product.
- **Advantages:** Integrates with common developer workflows.
- **Limitations:** Suggestions can be incorrect or insecure; review, test, and understand generated code.
- **Official documentation:** [GitHub Copilot docs](https://docs.github.com/en/copilot)

## Google AI Studio

- **Website:** [aistudio.google.com](https://aistudio.google.com/)
- **Category:** Model experimentation
- **Pricing:** Free access and quotas may be offered; limits and API terms vary.
- **Best for:** Trying Google's generative models and prototyping prompts.
- **Key features:** Model playground and API-oriented workflows.
- **Advantages:** Quick experimentation without setting up a full application.
- **Limitations:** Usage, regional availability, and data terms may vary; do not enter sensitive prompts.
- **Official documentation:** [Google AI for Developers](https://ai.google.dev/)

## Hugging Face Spaces

- **Website:** [huggingface.co/spaces](https://huggingface.co/spaces)
- **Category:** AI demos and hosting
- **Pricing:** Free options and paid compute tiers; quotas change.
- **Best for:** Exploring public machine-learning demos and building demos.
- **Key features:** Hosted interactive applications and model ecosystem.
- **Advantages:** Large community and open-source ecosystem.
- **Limitations:** Public apps may be unreliable; review model and space licenses and privacy before use.
- **Official documentation:** [Spaces documentation](https://huggingface.co/docs/hub/spaces)

## MLflow

- **Website:** [mlflow.org](https://mlflow.org/)
- **Category:** AI/ML experiment tracking and evaluation
- **Pricing:** Free and open source for self-managed use; hosted service plans vary.
- **Best for:** Tracking experiments and managing model-development workflows.
- **Key features:** Experiment tracking, model packaging, and evaluation capabilities.
- **Advantages:** Can be self-hosted for greater control.
- **Limitations:** Requires setup and operational ownership; review integrations and data flows.
- **Official documentation:** [MLflow docs](https://mlflow.org/docs/latest/)
