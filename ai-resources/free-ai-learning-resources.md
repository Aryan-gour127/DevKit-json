# Free AI learning resources

The materials below are freely accessible as learning resources at the time of writing. Hosted compute, certificates, platform quotas, and commercial APIs may have separate limits or charges.

| Resource | Focus | Suggested audience |
| --- | --- | --- |
| [Google ML Crash Course](https://developers.google.com/machine-learning/crash-course) | ML fundamentals and practical exercises | Beginners with basic programming |
| [fast.ai Practical Deep Learning](https://course.fast.ai/) | Hands-on deep learning | Learners with some Python |
| [Hugging Face course](https://huggingface.co/learn) | Transformers and model ecosystem | Developers exploring LLMs |
| [Elements of AI](https://www.elementsofai.com/) | Accessible AI concepts | General beginners |
| [Kaggle Learn](https://www.kaggle.com/learn) | Short courses in Python, data, and ML | Hands-on learners |
| [CS50's Introduction to AI with Python](https://cs50.harvard.edu/ai/) | Search, optimization, learning, and AI foundations | Learners comfortable with Python |
| [PyTorch tutorials](https://pytorch.org/tutorials/) | Deep-learning framework practice | Python developers |

Follow up with statistics, data ethics, evaluation, and model limitations. Do not deploy a model solely because a tutorial example works.
