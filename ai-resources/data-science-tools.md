# Data science tools

| Tool | Useful for | Pricing |
| --- | --- | --- |
| [Python](https://www.python.org/about/) | General-purpose language used across data workflows | Free and open source |
| [NumPy](https://numpy.org/doc/stable/) | Numerical arrays and vectorized operations | Free and open source |
| [pandas](https://pandas.pydata.org/docs/) | Tabular data cleaning and analysis | Free and open source |
| [Jupyter](https://jupyter.org/documentation) | Interactive notebooks and reproducible exploration | Free and open source |
| [Google Colab](https://colab.research.google.com/) | Hosted notebooks and optional compute | Free access with limits; paid plans and quotas change |
| [Kaggle](https://www.kaggle.com/) | Datasets, notebooks, and competitions | Free access with platform rules and compute limits |

Notebooks are useful for exploration but can hide execution order and dependencies. Restart and run all cells, document data sources, pin environments where appropriate, and keep credentials out of notebook files.
