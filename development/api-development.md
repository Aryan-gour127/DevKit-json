# API development

| Resource | Useful for | Audience |
| --- | --- | --- |
| [HTTP Semantics (RFC 9110)](https://www.rfc-editor.org/rfc/rfc9110.html) | Methods, status codes, and HTTP semantics | API developers |
| [MDN HTTP overview](https://developer.mozilla.org/en-US/docs/Web/HTTP/Overview) | Beginner-friendly web protocol concepts | Learners and frontend developers |
| [OpenAPI Specification](https://spec.openapis.org/oas/latest.html) | Describing HTTP APIs in a machine-readable format | API designers and tool users |
| [OpenAPI documentation](https://learn.openapis.org/) | Practical OpenAPI learning material | Beginners and API teams |
| [GraphQL Learn](https://graphql.org/learn/) | Queries, schemas, and GraphQL concepts | Developers exploring GraphQL |
| [Postman Learning Center](https://learning.postman.com/) | Sending requests and organizing API tests | API learners and testers |
| [OWASP API Security](https://owasp.org/API-Security/) | Common API security risks and mitigations | API developers and reviewers |

Document authentication, parameters, error responses, pagination, rate limits, and versioning. Do not assume that a successful request in a playground means an API is secure or production-ready.
