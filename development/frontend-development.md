# Frontend development

| Resource | Useful for | Audience |
| --- | --- | --- |
| [MDN Learn Web Development](https://developer.mozilla.org/en-US/docs/Learn) | Structured HTML, CSS, JavaScript foundations | Beginners and returning learners |
| [HTML Standard](https://html.spec.whatwg.org/) | Authoritative HTML behavior | Developers needing specification detail |
| [CSS reference](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference) | CSS properties, selectors, and values | All frontend developers |
| [JavaScript Guide](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide) | Language concepts and examples | Beginners through intermediate developers |
| [TypeScript Handbook](https://www.typescriptlang.org/docs/handbook/intro.html) | Static typing for JavaScript projects | JavaScript developers learning TypeScript |
| [React Learn](https://react.dev/learn) | Components, state, and React patterns | React learners |
| [Vue Guide](https://vuejs.org/guide/) | Vue concepts and application structure | Vue learners |
| [Angular documentation](https://angular.dev/overview) | Angular concepts and developer guides | Teams using Angular |

Start with semantic HTML, accessible forms and controls, responsive CSS, and browser fundamentals. Then choose a framework based on project needs rather than learning several at once.
