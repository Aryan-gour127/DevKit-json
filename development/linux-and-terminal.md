# Linux and terminal

| Resource | Useful for | Audience |
| --- | --- | --- |
| [Linux Journey](https://linuxjourney.com/) | Beginner Linux concepts and command practice | New Linux users |
| [GNU Bash manual](https://www.gnu.org/software/bash/manual/) | Bash language and shell behavior | Bash users |
| [The Linux man-pages project](https://www.kernel.org/doc/man-pages/) | Command and system-call reference | Linux users and developers |
| [Ubuntu documentation](https://help.ubuntu.com/) | Ubuntu-specific setup and administration | Ubuntu users |
| [PowerShell documentation](https://learn.microsoft.com/en-us/powershell/) | Cross-platform PowerShell and Windows shell usage | Windows and PowerShell users |

Commands differ between Linux distributions and shells. Check package-manager examples for your system; do not run commands from an untrusted source without understanding their effects.
