# Full-stack development

Full-stack work joins user interfaces, server APIs, data storage, testing, and deployment. Build a small vertical slice first: one form, one endpoint, one persistence operation, and one test.

| Resource | Useful for | Audience |
| --- | --- | --- |
| [MDN Learn](https://developer.mozilla.org/en-US/docs/Learn) | Web platform fundamentals | Beginners |
| [The Odin Project](https://www.theodinproject.com/) | Project-based full-stack learning paths | Self-directed learners |
| [Full Stack Open](https://fullstackopen.com/en/) | Modern JavaScript application development | Learners with basic programming knowledge |
| [React documentation](https://react.dev/learn) | Client UI concepts | Frontend learners |
| [Node.js documentation](https://nodejs.org/docs/latest/api/) | Server runtime APIs | Backend learners |
| [PostgreSQL tutorial](https://www.postgresql.org/docs/current/tutorial.html) | Relational data foundations | Developers learning persistence |
