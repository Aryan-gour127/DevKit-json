# Databases

| Resource | Useful for | Audience |
| --- | --- | --- |
| [PostgreSQL documentation](https://www.postgresql.org/docs/) | Relational SQL database concepts and reference | Developers and database learners |
| [MySQL reference manual](https://dev.mysql.com/doc/) | MySQL setup, SQL, and administration | MySQL users |
| [SQLite documentation](https://sqlite.org/docs.html) | Embedded relational database behavior | Beginners and application developers |
| [MongoDB Manual](https://www.mongodb.com/docs/manual/) | Document database modeling and operations | MongoDB learners |
| [Redis documentation](https://redis.io/docs/latest/) | In-memory data structures and Redis use | Developers exploring caching and data services |

Choose a database based on data relationships, consistency, query needs, operational constraints, and team experience. Learn backups, migrations, indexes, access control, and safe parameterized queries early.
