# Debugging and testing

| Resource | Useful for | Audience |
| --- | --- | --- |
| [Chrome DevTools](https://developer.chrome.com/docs/devtools/) | Inspecting web pages, network requests, and performance | Frontend developers and learners |
| [Firefox Developer Tools](https://firefox-source-docs.mozilla.org/devtools-user/) | Debugging in Firefox | Web developers |
| [Playwright documentation](https://playwright.dev/docs/intro) | Cross-browser end-to-end tests | Web teams and test authors |
| [Vitest guide](https://vitest.dev/guide/) | Unit and component testing in Vite projects | JavaScript and TypeScript developers |
| [pytest documentation](https://docs.pytest.org/en/stable/) | Python testing | Python developers |
| [Testing Library](https://testing-library.com/docs/) | User-centered UI tests | Frontend developers |

Test observable behavior, isolate failures, and keep test data disposable. Unit, integration, and end-to-end tests answer different questions; a passing suite does not prove the absence of defects.
