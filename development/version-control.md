# Version control

| Resource | Useful for | Audience |
| --- | --- | --- |
| [Pro Git book](https://git-scm.com/book/en/v2) | Git concepts from basics through internals | Beginners and experienced users |
| [Git reference](https://git-scm.com/docs) | Commands and configuration | Anyone using Git |
| [GitHub Skills](https://skills.github.com/) | Guided GitHub workflows | New GitHub users |
| [GitHub Docs](https://docs.github.com/en) | Repositories, branches, issues, and pull requests | GitHub contributors and maintainers |

Practice on a disposable repository. A commit records local history; `git push` publishes commits to a configured remote. Review [the Git and GitHub cheat sheet](../references/git-github-cheatsheet.md) before publishing.
