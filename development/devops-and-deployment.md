# DevOps and deployment

| Resource | Useful for | Audience |
| --- | --- | --- |
| [Docker Get Started](https://docs.docker.com/get-started/) | Images, containers, and local workflows | Beginners |
| [Kubernetes tutorials](https://kubernetes.io/docs/tutorials/) | Container orchestration concepts | Developers and operators |
| [GitHub Actions documentation](https://docs.github.com/en/actions) | Automating build and release workflows | GitHub project maintainers |
| [GitHub Actions quickstart](https://docs.github.com/en/actions/writing-workflows/quickstart) | Creating a first workflow | Beginners |
| [Vercel documentation](https://vercel.com/docs) | Web deployment platform concepts | Web developers |
| [Cloudflare Developer docs](https://developers.cloudflare.com/) | Edge, networking, and developer products | Web developers and operators |

Deployment services generally have plan limits and usage-based pricing. Review current terms before publishing. Keep secrets out of repositories and logs, use least-privilege access, and test rollback and backup procedures.
